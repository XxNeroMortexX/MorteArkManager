IMPORTANT CONFIGURATION
================================================================================

1. EDIT config.php:
   ----------------
   Required Settings:
   - ARK_ROOT: Full path to ARK server (e.g., C:\\ARKServers\\ARKASE)
   - BATCH_DIR: Where your batch files are stored
   - CONFIG_DIR: GameUserSettings.ini location
   - CLUSTER_DIR: Character transfer directory
   
   Server Configuration ($SERVERS array):
   - name: Server session name
   - map: Map name (Extinction, Fjordur, etc.)
   - rcon_ip: RCON IP (usually 127.0.0.1)
   - rcon_port: RCON port
   - port: Game port
   - query_port: Query port
   - save_dir: Save directory name (e.g., ExtinctionSave)
   - batch_file: Batch file identifier
   
   Player Mappings ($PLAYERS array):
   - Add Steam IDs and player names for character transfers

2. VERIFY PATHS:
   -------------
   CRITICAL: All paths must use DOUBLE BACKSLASHES!
   ✓ CORRECT: C:\\ARKServers\\ARKASE
   ✗ WRONG:   C:\ARKServers\ARKASE
   
   Why? PHP treats single backslash as an escape character.

3. RCON PASSWORD:
   --------------
   The manager automatically reads ServerAdminPassword from:
   GameUserSettings.ini → [ServerSettings] → ServerAdminPassword
   
   No need to enter RCON password separately!
   
   Make sure your server launch parameters include:
   - RCONEnabled=True
   - RCONPort=27020 (or your port)

4. BATCH FILES:
   ------------
   Organize your server startup batch files in BATCH_DIR.
   
   Example structure:
   C:\ARKServers\
   ├── start_extinction.bat
   ├── start_fjordur.bat
   └── start_theisland.bat
   
   Each batch file should start the ARK server with all parameters.

5. APACHE CONFIGURATION:
   ---------------------
   Add to httpd.conf:
   
   <Directory "H:/ark-manager">
       Options -Indexes +FollowSymLinks
       AllowOverride All
       Require all granted
   </Directory>
   
   Alias /ark-manager "H:/ark-manager"
   
   Then restart Apache:
   net stop Apache2.4 && net start Apache2.4

================================================================================
TROUBLESHOOTING GUIDE
================================================================================

PROBLEM: Can't Access Manager (Login Fails)
--------------------------------------------
Fix:
• Verify .htpasswd file exists: H:\ark-manager\.htpasswd
• Try recreating password:
  htpasswd -c H:\ark-manager\.htpasswd admin
• Check Apache error logs
• Ensure .htaccess is configured correctly

PROBLEM: RCON Connection Failed
--------------------------------
Fix:
1. Verify server is running (check Dashboard)
2. Check RCON port in config.php matches server
3. Ensure server launch parameters include:
   - RCONEnabled=True
   - RCONPort=27020
4. Check ServerAdminPassword is set in GameUserSettings.ini
5. Verify firewall isn't blocking RCON port
6. Test RCON with external tool (RCON CLI)

PROBLEM: Can't Start Server
----------------------------
Fix:
1. Verify batch file exists at configured path
2. Check batch file has correct executable path
3. Ensure no server instance is already running:
   tasklist | findstr ShooterGame
4. If found, use Force Kill first
5. Check server logs for startup errors
6. Verify ARK server files aren't corrupted
7. Check available disk space

PROBLEM: exec() Function Not Working
-------------------------------------
Fix:
1. Locate php.ini: php -i | findstr php.ini
2. Open php.ini in text editor
3. Find: disable_functions =
4. Remove: exec, shell_exec, proc_open, popen
5. Save php.ini
6. Restart Apache: net restart Apache2.4
7. Verify: php -r "var_dump(function_exists('exec'));"

PROBLEM: Permission Denied Errors
----------------------------------
Fix:
1. Run install.bat as Administrator
2. Manually set permissions:
   icacls "H:\ark-manager" /grant "NT AUTHORITY\SYSTEM:(OI)(CI)F" /T
   icacls "C:\ARKServers" /grant "NT AUTHORITY\SYSTEM:(OI)(CI)F" /T
3. Ensure Apache runs as LocalSystem (default)
4. Check folder ownership
5. Verify paths in config.php are correct

PROBLEM: Character Transfer Failed
-----------------------------------
Fix:
1. CRITICAL: Stop BOTH servers first
2. Check save directories exist:
   - Source: C:\ARKServers\ARKASE\ShooterGame\Saved\ExtinctionSave
   - Target: C:\ARKServers\ARKASE\ShooterGame\Saved\FjordurSave
3. Verify .arkprofile files exist in source
4. Check .arktribe files exist for tribes
5. Ensure write permissions on target directory
6. Review manager logs for specific error
7. Check cluster directory is accessible

PROBLEM: File Not Found Errors
-------------------------------
Fix:
1. Check all paths in config.php use double backslashes
2. Verify drive letters are correct (C:\ vs H:\)
3. Ensure directories actually exist
4. Use absolute paths, not relative
5. Check for typos in config.php
6. Use Manager Settings to verify paths

PROBLEM: INI Changes Not Taking Effect
---------------------------------------
Fix:
1. Verify you edited the correct INI file
2. Check the file was actually saved (check timestamp)
3. Restart the server (changes require restart)
4. Check for syntax errors in INI file
5. Some settings require server restart AND client restart
6. Verify setting is in correct [Section]

PROBLEM: System Monitor Shows No Data
--------------------------------------
Fix:
1. Ensure you're on Windows (System Monitor is Windows-only)
2. Check WMI service is running:
   net start winmgmt
3. Verify PHP can execute system commands
4. Check Windows Event Viewer for WMI errors
5. Restart WMI service:
   net stop winmgmt && net start winmgmt
6. Install hardware monitoring tools if needed

PROBLEM: Logs Not Updating
---------------------------
Fix:
1. Check auto-refresh is enabled (not paused)
2. Verify log directory exists and has write permissions
3. Check Apache has access to log directories
4. Ensure sufficient disk space
5. Review Apache error logs
6. Try manual refresh (F5)

PROBLEM: Scheduled Restarts Not Working
----------------------------------------
Fix:
1. Verify restart schedule is saved in Monitor
2. Check Windows Task Scheduler for created tasks
3. Ensure system time/date is correct
4. Verify batch files are accessible
5. Check manager logs for scheduling errors
6. Test batch files manually first

================================================================================
FINDING STEAM IDS
================================================================================

METHOD 1: From Save Files
--------------------------
1. Navigate to your save directory:
   C:\ARKServers\ARKASE\ShooterGame\Saved\ExtinctionSave\
   
2. Look for files like: 76561198012345678.arkprofile
   
3. The number IS the Steam ID!

4. Add to config.php:
   $PLAYERS = [
       '76561198012345678' => 'PlayerName',
   ];

METHOD 2: From Steam Profile
-----------------------------
1. Open Steam
2. View player's profile
3. Copy profile URL
4. Steam ID is the number in the URL:
   steamcommunity.com/profiles/76561198012345678/

METHOD 3: Use SteamID.io
-------------------------
1. Go to https://steamid.io/
2. Enter player's Steam profile URL or name
3. Copy the steamID64 value

SECURITY BEST PRACTICES
================================================================================

AUTHENTICATION:
---------------
✓ Use strong .htpasswd passwords (12+ characters)
✓ Different password for each admin user
✓ Only give access to trusted administrators
✓ Change passwords regularly (every 90 days)
✓ Log out when finished (don't stay logged in)

NETWORK SECURITY:
-----------------
✓ Use HTTPS in production (SSL certificate required)
✓ Restrict access by IP if possible
✓ Use VPN for remote administration
✓ Don't expose RCON ports to internet
✓ Keep Apache and PHP updated
✓ Use non-default ports for added security

FILE SECURITY:
--------------
✓ Review logs/manager.log regularly for suspicious activity
✓ Keep automatic backups enabled
✓ Backup config.php before making changes
✓ Limit File Browser access to necessary directories
✓ Clean old backup files periodically
✓ Never share your .htpasswd file

SERVER SECURITY:
----------------
✓ Use strong ServerAdminPassword
✓ Use strong ServerPassword (if private server)
✓ Keep ARK server updated to latest version
✓ Monitor server logs for hack attempts
✓ Use BattlEye anti-cheat if supported
✓ Regularly check for unauthorized admin users

ACCESS CONTROL:
---------------
✓ Use Admin role only for trusted administrators
✓ Use Moderator role for limited access users
✓ Review user roles regularly
✓ Remove access for inactive users
✓ Log all administrative actions

BACKUP STRATEGY:
----------------
✓ Daily: Character files and save files
✓ Weekly: Full ARK server directory
✓ Monthly: Complete system backup
✓ Before Updates: Everything
✓ Store backups off-server (external drive/cloud)
